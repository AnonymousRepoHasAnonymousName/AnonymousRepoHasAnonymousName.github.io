Third-Party Licenses
====================

UrbanVerse makes use of several third-party libraries, assets, and pretrained models, each governed by their own respective licenses. To ensure clarity and proper attribution, all third-party license texts and usage notes have been included in the ``licenses/`` directory at the root of this repository.

Third-Party Components
----------------------

Please refer to the files in ``licenses/`` for details on:

- **Open-source libraries**: Such as Isaac Lab (BSD-3-Clause) and other dependencies

- **Pretrained models**: Checkpoints hosted on HuggingFace and other model repositories

- **Environment and object assets**: 3D assets and scene data converted from public sources

- **External datasets**: Datasets and simulation tools used by UrbanVerse

- **Additional dependencies**: Other third-party software components

License Information
-------------------

These files document the permitted usage, redistribution terms, and credit requirements of the respective third-party components. When using UrbanVerse, please ensure compliance with all applicable third-party licenses.

For detailed license information, please refer to:

- ``licenses/dependencies/``: License files for Python packages and dependencies

- ``licenses/assets/``: License information for robot assets and 3D models

Each license file contains the full legal text and attribution requirements for the respective component.
