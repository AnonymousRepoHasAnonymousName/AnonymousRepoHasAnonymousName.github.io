API Reference
=============

This section provides comprehensive API documentation for all UrbanVerse modules and functions. The APIs are organized by functional area for easy navigation.

UrbanVerse APIs are organized into several main modules:

- **UrbanVerse-100K**: Dataset access and asset management
- **UrbanVerse-Gen**: Real-to-sim scene generation pipeline
- **Navigation (RL)**: Reinforcement learning environment creation and training
- **Navigation (IL)**: Imitation learning data collection, training, and evaluation
- **Assets**: Asset annotation and management
- **Teleoperation**: Manual robot control interfaces
